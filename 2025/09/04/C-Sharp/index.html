.NET平台与框架

.NET 是“平台”，而 ASP.NET 是建立在 .NET 平台之上的“框架”

.NET 平台的主要“分支”或实现包括：

  • .NET Framework (旧)：原始的 .NET，仅限 Windows。

  • .NET Core (跨平台重生)：现代、跨平台、高性能的开源实现。

  • .NET 5/6/7/8+ (统一平台)：.NET Core 的后续版本，统一了整个 .NET 生态系统，是未来的方向。

ASP.NET 是 专门基于 .NET 平台来构建 Web 应用程序和服务的框架

ASP.NET 本身也有两个主要版本：

  • ASP.NET (基于 .NET Framework)：传统的 Web 框架，用于在 Windows 上构建 Web Forms、MVC 应用。（旧）

  • ASP.NET Core (基于 .NET Core / .NET 5+)：现代、跨平台、高性能、开源的重写版本。它是构建新 Web 项目的默认和推荐选择。

C# ABP 框架（ASP.NET Boilerplate / Application Building Platform）是基于 ASP.NET Core 构建的非微软官方框架

.NET Core独立部署

可以把.NET Core运行时环境和开发的程序打包到一起部署。目标服务器就不需要预先安装任何 .NET Core 运行时或 SDK。
在 Windows 系统上发布 最终会生成一个单独的、以你的项目名命名的 .exe 可执行文件。
在 Linux / macOS 系统上发布 生成的是一个没有后缀的单独可执行文件（在 Linux 上）或一个特殊的可执行文件（在 macOS 上）

Entity Framework Core（EF Core）

是一个ORM框架，用于提高开发效率，让开发人员减少对数据库的关注，即使不会写SQL也能实现数据的持久化。它的底层是ADO.NET，通过它访问数据库。
Code First模式：先编写实体类代码，生成数据库表结构
DataBase First模式：先创建数据库表结构，生成对应实体类

IEnumerable 与 IQueryable
Enumerable类中定义的供普通集合用的Where等方法都是“客户端评估（把数据加载到内存，在内存中筛选数据）”，因此微软创造了IQueryable类型，它使用的是“服务器端评估（使用SQL语句在数据库服务器上完成数据筛选的过程）”。

DataReader 和 DataTable

DataReader的优点是客户端内存占用小，缺点是如果遍历读取数据并进行处理的过程缓慢的话，会导致程序占用数据库连接的时间较长，从而降低数据库服务器的并发连接能力；DataTable的优点是数据被快速地加载到了客户端内存中，因此不会较长时间地占用数据库连接，缺点是如果数据量大的话，客户端的内存占用会比较大。

ASP.NET Core（官方开源框架）

  1. 掌握 C# 语言基础与高级特性：

    • 基础：变量、数据类型、控制流、类、接口、继承、多态。
    • 高级/关键：async/await 异步编程、LINQ、委托与事件、Lambda 表达式、泛型、反射（Reflection）、特性（Attributes）、Span<T> 和内存管理基础。这些是理解框架内部运作的关键。
    • 资源：官方文档、《C# in Depth》等书籍。

  2. **熟悉 .NET 运行时 (CLR/CoreCLR) 和基础库 (BCL)**：

    • 了解程序集（Assembly）、类型系统、垃圾回收（GC）机制、AppDomain（.NET Framework）或程序集加载上下文（AssemblyLoadContext - .NET Core）的基本概念。
    • 熟悉常用的 BCL 类型，如 Task, HttpClient, Stream, Configuration 等。

  3. 精通 ASP.NET Core 应用开发：

    • 创建项目：熟练使用 dotnet new 命令行或 IDE 创建 Web API、MVC、Razor Pages 等项目。
    • 核心概念实践：
      • **依赖注入 (DI)**：IServiceCollection, IServiceProvider, 生命周期（Singleton, Scoped, Transient）。
      • 配置系统：IConfiguration, 各种配置源（JSON, 环境变量, 命令行等）。
      • **中间件 (Middleware)**：理解请求处理管道（Request Pipeline），能编写自定义中间件。
      • **路由 (Routing)**：Endpoint Routing, 属性路由（Attribute Routing）。
      • 控制器 (Controllers) / Razor Pages：模型绑定（Model Binding）、模型验证（Model Validation）、过滤器（Filters）。
      • **日志 (Logging)**：ILogger 接口及不同日志提供程序。
      • **主机 (Host)**：IHostBuilder, IWebHostBuilder (旧版), 通用主机（Generic Host）的概念。
    • 资源：微软官方 ASP.NET Core 文档是最佳起点，配合动手实践项目。

ABP （非微软官方开源框架）

官网 http://www.aspnetboilerplate.com
博客 https://www.cnblogs.com/mienreal/p/4528470.html

ASP.NET Boilerplate 基于DDD的经典分层架构思想，实现了众多DDD的概念

ABP框架已实现了以下特性：

  • 多语言/本地化支持
  • 多租户支持（每个租户的数据自动隔离，业务模块开发者不需要在保存和查询数据时写相应代码）
  • 软删除支持（继承相应的基类或实现相应接口，会自动实现软删除）
  • 统一的异常处理（应用层几乎不需要处理自己写异常处理代码）
  • 数据有效性验证（Asp.NET MVC只能做到Action方法的参数验证，ABP实现了Application层方法的参数有效性验证）
  • 日志记录（自动记录程序异常）
  • 模块化开发（每个模块有独立的EF DbContext，可单独指定数据库）
  • Repository仓储模式（已实现了Entity Framework、NHibernate、MangoDB、内存数据库）
  • Unit Of Work工作单元模式（为应用层和仓储层的方法自动实现数据库事务）
  • EventBus实现领域事件(Domain Events)
  • DLL嵌入资源管理
  • 通过Application Services自动创建Web Api层（不需要写ApiController层了）
  • 自动创建Javascript 的代理层来更方便使用Web Api
  • 封装一些Javascript 函数，更方便地使用ajax、消息框、通知组件、忙状态的遮罩层等
